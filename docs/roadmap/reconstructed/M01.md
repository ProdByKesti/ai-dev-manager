# M01 — Application Foundation

Review draft: package IDs/titles and milestone scope retained; detailed requirements, owners, dependencies and test cases newly reconstructed. Not yet approved or executed.

- Tauri 2, Rust/Tokio, SQLite/SQLx, React/TypeScript, Vite/Tailwind, Serde JSON-RPC. Independent Rust core is sole DB writer; named pipes with restricted ACL plus client authorization are a candidate, not a proven same-user boundary.
- Provisional baseline targets: combined idle RAM below 250 MB, CPU below 1%, cold launch below 5 s, reconnect below 2 s, IPC below 100 ms; define hardware and measurement method, do not claim measured results.
