# M08 — Linear Integration

Review draft: retained package IDs/titles and scope; detailed requirements, owners, dependencies and test cases reconstructed, not yet approved or executed.

- Existing Linear owns agreed synchronized fields; ADM owns internal run/gate/evidence. New projects off; imported initially read-only until approval; off/import/export/bidirectional. No auto deletes or chat upload.
- 60s active/5min idle polling proposed; 2 technical retries, verify ambiguous effects, no inference for sync. T12 in-memory evidence only, no atomic or exactly-once guarantee (K12). Public OAuth M11 gate; isolated synthetic test workspace.
