# M04 — Agent Management

Review draft: package IDs/titles and milestone scope retained; detailed requirements, owners, dependencies and test cases newly reconstructed. Not yet approved or executed.

- Separate role, identity, provider session, execution run. Proposed defaults: 12 completed tasks/session, 1 active turn/session, 3 question rounds, 8 automated technical messages, 4 extra communication inference calls, 1 temporary specialist/task. Budgets cumulative; cross-project routing denied by default. No paid fallback.
- Provisional scale: 100 identities, 10k memory records/project; search <200 ms, context <500 ms, message <100 ms, archives <200 ms. FTS5 initially; semantic retrieval later.
