# M12 — Extended Platform

Review draft: retained package IDs/titles and scope; detailed requirements, owners, dependencies and test cases reconstructed, not yet approved or executed.

- Six proposed independent extension release scopes 0.2–0.7; no dates, actual versions and scope require approval. P1 packages 01–06, P2 07–14, 15/16 per selected release. Native GitHub/Linear sync distinct from MCP tool integration. Optional providers only permitted auth, no automatic switch; optional paid use requires explicit separate consent.
- Autonomous planning off by default; proposed cycle max 5 new tasks, 2 revisions, 5 planning calls, 60 min review; no rights/cost escalation or public release; cumulative budgets. Full safe recovery >=90% of defined scenarios is hypothesis, not universal claim. Local hardware test required.
- Release-specific prerequisites for M12-15 are conditional on selected scope; M12-16 follows its validation, not every extension at once.
