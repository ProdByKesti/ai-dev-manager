# M11 — Public MVP

Review draft: retained package IDs/titles and scope; detailed requirements, owners, dependencies and test cases reconstructed, not yet approved or executed.

- Public beta proposed v0.1.0-beta.1 then v0.1.0; optional 3–10 external testers, no invented participation. Local-only use without account, no paid fallback, no mandatory hosting. K01/K13 provider terms/public auth, costs, Windows signing and supported OS/test environment require evidence.
- Signed updater trust separate from Windows Authenticode; key rotation/revocation and anti-downgrade; no silent WSL/admin changes, preserve data on uninstall, no update during active tasks, verified backup before migration/update. No publishing without separate authorization.
