# T09 — Model and effort capabilities

Status: Demonstrated within probe. Historical feasibility investigation completed; production acceptance not implied.

Evidence basis: reconstructed from retained Phase 0 test summaries and reported historical observations. Raw logs, scripts and complete original console transcripts are not available in this documentation pass. No new execution was performed; the report is not independently reproduced evidence. Private paths, identifiers, account data and credentials are intentionally omitted.

## Objective

Discover provider models and test selectable effort settings.

## Reported observations

The historical model/list response reported eight variants: GPT-6.1 Terra/Sol, GPT-6 Astra/Sol/Luna and GPT-5.6 Sol/Terra/Luna. Reported effort options included low, medium, high, xhigh, max and ultra, with the reported Luna variants extending only through max. GPT-6.1 Terra low and GPT-6 Luna medium were exercised and their resolved settings matched the selections.

## Design implications

Discover current model IDs and capabilities dynamically. The names and options are historical observations, not a current catalogue or compatibility promise.

## Limitations and required validation

Availability can change by account, version and provider. Test unsupported settings, capability refresh, model changes and approved bounded escalation.
